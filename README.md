# AI Off, Timer On — the FizzBuzz Challenge

This is the exact challenge from Survives Production's video **"I Turned Off AI And Timed My Own Debugging"** (AI Critical Thinking, Episode 1).

## The rules

- AI assistant fully off — no Copilot, no Claude Code, no ChatGPT tab open.
- A 3-minute timer, treated as a cap, not a target.
- Write a solution to the prompt below, cold, out loud.

## The prompt

> Print the numbers 1 to 100, but for multiples of 3 print "Fizz", multiples of 5 print "Buzz", and multiples of both print "FizzBuzz".

## Try it yourself first

Before you open `fizzbuzz.py`, set your own timer and write your own version. That's the actual point of the video — not whether FizzBuzz is hard, but whether the muscle is still there when the AI training wheels come off.

## Reference solution

`fizzbuzz.py` has a clean, working solution once you're ready to check your work.

## Why this exists

The data says AI use is quietly eroding debugging and problem-solving skills for a lot of engineers. Anthropic's own research found developers using AI coding assistants scored 17% lower on comprehension tests than developers who coded manually. This repo is a 5-minute way to check where you stand — no signup, no cost, just a timer.

Full context and the AI-on vs. AI-off comparison: [Survives Production on YouTube](https://youtube.com/@survivesproduction).
